# 자동회전 런처 (Auto-Rotate Launcher)

홈 화면 위젯을 누르면 **갤럭시 자동 회전을 켜고 등록한 앱 1개를 실행**하고, 그 앱을
벗어나면 **자동 회전을 끄고 세로로 되돌리는** 오프라인 유틸리티입니다.
갤럭시 S24(One UI) 기준으로 설계·검증했습니다.

## 동작

```
위젯/바로가기 탭
   ↓
① 갤럭시 자동회전 ON  (퀵패널 토글과 동일)
② 등록된 앱 실행
   ↓  (앱 사용 중 — 폰을 돌리는 대로 화면이 따라감)
③ 앱 이탈 감지 (뒤로/홈/앱전환/화면꺼짐)
   ↓
자동회전 OFF + 세로 고정 복귀
```

- 등록 가능한 앱은 **1개**입니다.
- 상시 알림(포그라운드 서비스) 사용 안 함
- 인터넷 권한 없음 — 완전한 오프라인 앱
- 화면 내용은 읽지 않고 **최상단 앱의 패키지명만** 사용

## 기술 구조

| 파일 | 역할 |
|---|---|
| `rotation/AutoRotate.kt` | `ACCELEROMETER_ROTATION` / `USER_ROTATION` 으로 자동회전 ON/OFF |
| `session/SessionStarter.kt` | 자동회전 ON → 감시 시작 → 앱 실행 |
| `service/ExitWatchService.kt` | 접근성 서비스. 앱 이탈·화면꺼짐 감지 후 세로 복귀 |
| `service/SessionState.kt` | 세션 공유 상태 |
| `widget/StartWidgetProvider.kt` | 홈 화면 위젯 (1×1, 등록된 앱 이름 표시) |
| `data/AppSettings.kt` | 등록된 앱 1개 저장 |

### 오탐 방지
자동회전을 켜면 화면이 회전하며 배경 창이 잠깐 포그라운드로 보고되어, 이를 "앱 이탈"로
오인하는 문제가 있었습니다. 두 장치로 해결했습니다.

- **시작 유예 2초** — 대상 앱이 처음 보이기 전의 실행/회전 잡음 무시
- **이탈 디바운스 0.6초** — 다른 창이 잠깐 스쳐도 곧바로 되돌리지 않고, 그 사이 대상 앱이
  다시 앞으로 오면 세션 유지
- 키보드·월페이퍼·시스템UI 등 실행 불가 패키지는 앱 전환으로 보지 않음

## 권한

- `WRITE_SETTINGS` — 자동 회전 제어. **앱 안에서 부여, PC/adb 불필요**
- `QUERY_ALL_PACKAGES` — 등록할 앱 목록 조회(패키지명만 사용)
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` — One UI 절전으로 서비스가 잠드는 것 방지(권장)

> INTERNET, SYSTEM_ALERT_WINDOW(다른 앱 위에 표시)는 **선언하지 않습니다.**

## 사용법

1. 앱 실행 → **앱 등록하기** 로 실행할 앱 1개 선택
2. **준비 상태**에서 `설정 수정 허용`, `접근성 서비스` 를 켬 (배터리 절전 예외는 권장)
3. 홈 화면 빈 곳 길게 누르기 → **위젯** → **자동회전 런처** 배치
4. 위젯을 누르면 자동회전이 켜지고 등록한 앱이 실행됨

앱 안의 **지금 실행** 버튼으로도 동일하게 시작할 수 있습니다.

## 빌드

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

릴리스(서명) 빌드는 `local.properties.sample` 을 참고해 keystore 정보를 채운 뒤
`./gradlew assembleRelease` — `local.properties` 와 keystore 는 커밋되지 않습니다.

## 알려진 한계

- 안드로이드는 다른 앱을 **강제 종료**시킬 수 없어, 대상 앱은 백그라운드에 남을 수 있습니다.
  (화면 방향은 즉시 세로로 복귀합니다.)
- 다른 앱을 **전체화면(몰입 모드)** 으로 강제하는 것도 불가능합니다(안드로이드 9에서 폐지).
  전체화면은 해당 앱 자체 설정이나 `설정 > 디스플레이 > 전체 화면 앱` 을 사용하세요.
- 절전 예외를 설정하지 않으면 One UI 가 접근성 서비스를 재워 이탈 감지가 늦어질 수 있습니다.
