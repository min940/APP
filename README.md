# 🎮 온가족 게임 (Family Game Site)

50대 아빠 · 40대 엄마 · 초등학교 5학년 자녀가 **각자 핸드폰으로 접속해 함께** 즐기는 실시간 게임 사이트입니다.
한 명이 방을 만들고 **4자리 방 코드**를 가족에게 알려주면, 모두 같은 방에 들어와 게임을 합니다.

## 게임 4종

| 게임 | 설명 | 인원 |
|------|------|------|
| 🧠 스피드 퀴즈 | 상식 퀴즈를 각자 풀고 빠르고 정확하게 맞힐수록 높은 점수 | 1명 이상 |
| 👨‍👩‍👧‍👦 가족 퀴즈 | 우리 가족만 아는 생일·추억 문제 (직접 편집 가능) | 1명 이상 |
| 🎨 캐치마인드 | 한 명이 그림을 그리고 나머지가 채팅으로 정답 맞히기 | 2명 이상 |
| 🔤 끝말잇기 | 순서대로 단어 이어가기 (두음법칙 지원, 목숨 3개) | 2명 이상 |
| ⚡ 반응속도 | 초록불이 켜지는 순간 가장 빨리 누른 사람이 승리 | 1명 이상 |

## 실행 방법

```bash
npm install
npm start
```

기본 포트는 `3000`입니다. 브라우저에서 `http://localhost:3000` 접속.
포트를 바꾸려면 `PORT=8080 npm start`.

### 같은 집(와이파이)에서 함께 하기

1. 게임을 실행할 컴퓨터의 로컬 IP를 확인합니다 (예: `192.168.0.10`).
2. 각자 핸드폰 브라우저에서 `http://192.168.0.10:3000` 으로 접속합니다.
3. 한 명이 **새 방 만들기** → 방 코드 공유 → 나머지가 **방 참여하기**.

### 인터넷 어디서든 접속하기 (무료 배포 — Render)

집 밖에서도, 서로 다른 장소에서도 접속하려면 무료 호스팅에 배포합니다.
이 저장소에는 배포 설정(`render.yaml`)이 포함되어 있어 클릭 몇 번이면 됩니다.

1. [render.com](https://render.com) 가입 (GitHub 계정으로 로그인 추천)
2. 대시보드 → **New +** → **Blueprint** 선택
3. 이 GitHub 저장소(`min940/game`)를 연결하고 브랜치를 고름
4. Render가 `render.yaml`을 읽어 자동으로 서비스를 생성 → **Apply**
5. 몇 분 뒤 `https://family-game-xxxx.onrender.com` 같은 주소가 생김
6. 이 주소를 가족에게 공유하면 **어디서든** 각자 핸드폰으로 접속!

> 무료 플랜은 한동안 아무도 접속하지 않으면 잠자기 상태가 되어, 다음 첫 접속이 30초쯤 걸릴 수 있어요(이후엔 빠름). Railway·Fly.io 등 다른 호스팅도 `npm start` / `PORT` 환경변수만으로 동일하게 동작합니다.

## 기술 구성

- **서버**: Node.js + Express + [Socket.IO](https://socket.io/) (실시간 양방향 통신)
- **프론트엔드**: 순수 HTML/CSS/JS (빌드 과정 없음), 모바일 우선 반응형 UI
- 방 상태는 서버 메모리에 저장 (DB 불필요). 서버 재시작 시 방은 초기화됩니다.

## 폴더 구조

```
server.js              # Express + Socket.IO 서버, 소켓 이벤트 라우팅
src/
  rooms.js             # 방/플레이어 관리 (방 코드 생성, 방장 위임 등)
  games/
    index.js           # 게임 모듈 등록
    quiz.js            # 스피드 퀴즈 서버 로직
    catchmind.js       # 캐치마인드 서버 로직
    wordchain.js       # 끝말잇기 서버 로직 (한글 두음법칙 규칙 포함)
    reaction.js        # 반응속도 서버 로직
data/
  quiz.json            # 퀴즈 문제
  draw-words.json      # 캐치마인드 제시어
public/
  index.html           # 진입 페이지
  style.css            # 스타일 (다크 테마, 큰 버튼)
  js/
    app.js             # 클라이언트 메인 (화면 라우팅, 소켓, 로비/결과)
    games/*.js         # 게임별 화면 UI
```

## 게임/문제 추가하기

- **퀴즈 문제 추가**: `data/quiz.json` 에 `{ "q": "질문", "choices": ["보기1","보기2","보기3","보기4"], "answer": 정답번호(0~3) }` 형태로 추가.
- **가족 퀴즈 personalize**: `data/family-quiz.json` 을 열어 우리 가족에 맞게 고칩니다. `q`(질문), `choices`(보기 4개), `answer`(정답 보기 번호, **맨 앞이 0**, 그다음 1, 2, 3)를 바꾸면 돼요. 예) 아빠 생일이 6월이고 보기가 `["3월","6월","9월","12월"]`이면 `answer`는 `1`. 파일을 저장하면 다음 게임부터 바로 반영됩니다(서버 재시작 불필요).
- **캐치마인드 단어 추가**: `data/draw-words.json` 배열에 단어 추가.
- **새 게임 추가**: `src/games/`에 모듈을 만들고 `src/games/index.js`에 등록, `public/js/games/`에 화면 파일 추가 후 `index.html`에 스크립트 태그 추가.
