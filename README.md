# 🎮 우리집 게임방 (Family Game Site)

온 가족(아빠·엄마·아이)이 **각자 핸드폰으로 같은 방에 접속해서** 함께 즐기는 실시간 멀티플레이 게임 사이트입니다.

한 명이 방을 만들고 **4자리 방 번호**를 가족에게 알려주면, 각자 폰에서 번호를 입력해 같은 방에 모여 게임을 합니다.

## 🕹️ 지금 있는 게임 (3종)

| 게임 | 설명 |
|------|------|
| 🎯 **퀴즈 배틀** | 온 가족 상식 문제를 누가 가장 빨리 맞히나! (빠를수록 보너스 점수) |
| 🎨 **그림 맞히기** | 돌아가며 한 명이 그리면 나머지가 채팅으로 정답 맞히기 (캐치마인드) |
| 🔢 **빙고** | 각자 랜덤 5×5 판에서 돌아가며 숫자를 외쳐 먼저 3줄을 완성하면 승리 |

- 📱 모바일 세로화면에 최적화, 큰 글씨·큰 버튼 (부모님도 편하게)
- 👨‍👩‍👧 최대 8명까지 함께 플레이

## ▶️ 로컬에서 실행하기

```bash
npm install
npm start
```

실행 후 브라우저에서 `http://localhost:3000` 접속.

**같은 집 와이파이의 다른 폰에서 접속하려면** 컴퓨터의 내부 IP를 확인해서
`http://<컴퓨터IP>:3000` 으로 접속하세요. (예: `http://192.168.0.5:3000`)

```bash
# 내부 IP 확인 (Mac/Linux)
ipconfig getifaddr en0    # 또는:  hostname -I
```

> 개발 중 자동 재시작: `npm run dev`

## 🌐 인터넷에 배포해서 어디서나 접속하기 (무료)

집 밖에서도 각자 폰으로 접속하려면 아래 무료 호스팅에 올리면 됩니다.
실시간 통신(WebSocket)을 지원하는 곳이어야 합니다.

### Render (추천, 무료)
1. 이 저장소를 GitHub에 올립니다.
2. [render.com](https://render.com) 가입 → **New → Web Service** → 이 저장소 선택
3. 설정값:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. 배포되면 나오는 주소(`https://xxxx.onrender.com`)를 가족에게 공유하세요.

> 포트는 코드가 `process.env.PORT`를 자동으로 사용하므로 따로 설정할 필요가 없습니다.
> Railway, Fly.io, Glitch 등 다른 Node.js 호스팅에서도 동일하게 동작합니다.

## 🧩 폴더 구조

```
server.js            실시간 서버 (Express + Socket.IO), 방 관리 & 게임 로직
games/
  quizData.js        퀴즈 문제 은행 (여기에 문제를 추가하세요)
  drawData.js        그림 맞히기 제시어 목록
public/
  index.html         전체 화면 구조 (홈 / 대기실 / 게임 / 결과)
  style.css          귀여운 가족용 디자인
  js/
    core.js          공용 로직 (접속·방·채팅·점수판·화면전환)
    quiz.js          퀴즈 게임 화면
    bingo.js         빙고 게임 화면
    draw.js          그림 맞히기 화면 (캔버스)
```

## ✏️ 쉽게 커스터마이징

- **퀴즈 문제 추가/수정**: `games/quizData.js` — 우리 가족만의 문제를 넣어보세요!
  ```js
  { q: "우리 강아지 이름은?", choices: ["초코", "보리", "콩이", "구름"], answer: 0, explanation: "정답은 초코!" }
  ```
- **그림 제시어 추가**: `games/drawData.js` 의 단어 목록에 추가.
- **색상 테마**: `public/style.css` 맨 위 `:root` 의 색 변수만 바꾸면 전체 분위기가 바뀝니다.
